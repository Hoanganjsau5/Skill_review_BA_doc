# Examples

Ví dụ dùng để **validate** criteria/rules (bước 6 của pipeline).

Quy ước đặt tên: `<criterion_or_rule_id>-pass-<n>.md`, `<criterion_or_rule_id>-fail-<n>.md`.

Mỗi ví dụ gồm:
- Đoạn artifact mẫu (tự viết hoặc có quyền sử dụng; không dùng tài liệu dự án thật khi chưa được phép).
- Kết quả mong đợi (pass/fail) và lý do.
- Finding mong đợi (nếu fail).
